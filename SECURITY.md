# Güvenlik Raporlaması

## Kapsam

HyperSeed tamamen çevrimdışı çalışan bir uygulamadır:

- Uygulama hiçbir sunucuya bağlanmaz, internet izni yoktur.
- Telemetri, analitik veya hata raporlama yoktur.
- Tüm veriler cihazda Hive ile saklanır.
- Depoda gizli anahtar, API anahtarı veya imzalama anahtarı bulunmaz.

## Bir güvenlik açığı mı bildirmek istiyorsun?

Kaynak kodu açık olduğundan güvenlik endişelerini [GitHub Security Advisories](https://github.com/labirend/hyperseed/security/advisories) üzerinden özel olarak bildirebilirsin. Lütfen herkese açık issue açma; kullanıcı verisi sızıntısı riski varsa doğrudan raporla.

Şu ana kadar bilinen bir güvenlik açığı yoktur.
